# Project Title and Authorization

The Library Management System was authorized on 2026-11-16. It replaces the paper logbook used by the school library to record borrowed books.

# Start and Finish Dates

The project starts on 2026-11-20 and finishes on 2027-02-26.

# Budget Information

The approved budget is 40,000 for development and 12,000 for the first year of operation.

# Project Objectives

- Record every loan and return in one database.
- Let students search the catalogue by title, author, or subject.
- Send an overdue notice three days after the due date.

# Success Criteria

- All loans are recorded in the system by the end of the first month of use.
- A search returns results in under two seconds.
- The librarian can produce a monthly loan report without help from the team.
